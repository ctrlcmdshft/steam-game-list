# Steam Game List

A static, mobile-friendly Steam game catalogue for GitHub Pages. It includes search, optional A–Z sorting, duplicate quantity badges, direct Steam-client links, and Store links that open in a new tab.

## Publish with GitHub Pages

1. Create a new GitHub repository (for example, `steam-game-list`) and upload these files to its default branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the default branch and the **/(root)** folder, then save.
4. GitHub will show the public site URL after it deploys — typically `https://YOUR-USERNAME.github.io/steam-game-list/`.

The page is entirely static: it needs no hosting account beyond GitHub Pages and no build process.
